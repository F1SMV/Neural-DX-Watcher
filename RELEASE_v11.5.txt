🎯 CHANGEMENTS v11.5 — Configuration persistante
═════════════════════════════════════════════════

**MY_CALL et user_qra PERSISTES dans data/config.json**

  ✓ Au premier lancement, l'app crée automatiquement data/config.json
  ✓ MY_CALL et user_qra y sont sauvegardés
  ✓ À chaque redémarrage/redéploiement, ils sont restaurés automatiquement
  ✓ Plus besoin de ressaisir le call ou le locator !

AVANT v11.5 :
  ✗ Chaque redémarrage : user_qra revenait à DEFAULT_QRA
  ✗ Chaque mise à jour : MY_CALL revenait au hardcoded
  ✗ Frustration utilisateur = ressaisir à chaque fois

APRÈS v11.5 :
  ✓ Configuration "définitive" jusqu'à un prochain changement volontaire
  ✓ Deux façons de changer :
    1. Éditer webapp.py ligne ~89 : MY_CALL = "..."
    2. Éditer data/config.json directement :
       {
         "my_call": "F1SMV",
         "user_qra": "JN23",
         "timestamp_utc": "..."
       }

Nouvelle route API : POST /api/update_mycall
  (pour les changements futurs via interface)


📋 DÉPLOIEMENT SUR LE PI
═════════════════════════

1. Extraire l'archive :
   $ cd ~/Spot-Watcher-DX
   $ tar -xzf Neural-DX-Watcher-v11.5.tar.gz

2. Redémarrer Flask :
   $ pkill -9 python3
   $ sleep 2
   $ ./start.sh

3. Au premier lancement, data/config.json est créé automatiquement.
   Vérifier :
   $ ls -la ~/Spot-Watcher-DX/data/config.json
   $ cat ~/Spot-Watcher-DX/data/config.json

4. Vérifier les logs :
   $ tail -30 ~/Spot-Watcher-DX/radio_spot_watcher.log | grep "11.5\|Config\|MY_CALL"


🔄 MIGRATION DEPUIS v11.4
═════════════════════════

La première fois avec v11.5 :

  1. L'app démarre
  2. Cherche data/config.json → absent
  3. Crée le fichier avec les valeurs par défaut :
     MY_CALL = celle de webapp.py (hardcodée)
     user_qra = DEFAULT_QRA = "JN23"
  4. Sauvegarde le fichier
  5. À partir du prochain redémarrage, ces valeurs sont restaurées

Si tu avais changé user_qra avant, il faudra le ressaisir une seule fois
et il sera alors persistant pour tous les futurs redémarrages.
